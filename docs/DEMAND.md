# 用户真正会付钱的需求

调研截至 2026-09。来源：r/travel、r/TravelHacks、r/solotravel、Lonely Planet 是否还值得买的讨论、Vogue 对会员制旅行推荐的报道、GoingSolo / Wanderlog 类行程工具、以及我们自己储物柜上线后的产品形态。

## 1. 他们打开这座网站，心里在问什么

不是「东京有什么好玩的」。Google、TikTok、AI 已经把景点堆满了。打开城市指南的人，通常已经订了机票，或正在决定要不要订。真正的问题是：

1. **这几天去会不会踩雷。** 周一闭馆、罢工、黄金周、雨季、时尚周。Reddit 上 91% 看过旅游帖的美国人据此做过预订决策；他们要的是「现在」不是「这座城的永恒画像」。
2. **住哪儿才不会每天浪费一小时。** 最贵的错误不是餐厅，是住错街区：威尼斯城外城堡、罗马 Termini 西侧、曼谷不靠 BTS。这是一笔住三晚就后悔的钱。
3. **什么必须现在订，什么可以到了再看。** 吉卜力抽签、圣家堂、teamLab、卢浮宫、高档餐厅。过了提前期，不是「挤一挤」，是「这趟没有了」。
4. **别被宰。** 机场黄牛、城市通票、Narita 出租车、CDG 黑车。一单就超过一年会员费。
5. **规划本身太累。** r/TravelHacks 里第二高频不是签证，是「信息太多而且不好」。他们付钱是为了少开二十个标签页。
6. **落地四小时别做蠢事。** 时差、热、海拔、末班车。过境卡有用，但单独躺在储物柜里没有购买理由——它必须嵌进「我这几天」。

纸质指南 2026 年还在卖，是因为：**可信的筛选 + 断网还能看**。LP 过时的是价目和店名；不过时的是「什么值得你的时间」。Reddit 赢在新鲜，输在你要自己当编辑。

## 2. 人们付钱的订阅，从来不是「更多文章」

| 他们买的 | 例子 | 我们错在哪 |
|---|---|---|
| 省下的钱或时间，能算出来 | Thrifty Traveler 机票警报、$8 Obscura 换团费折扣 | 储物柜无法算 ROI |
| 信任基础设施 | 私人推荐、会员旅行团审核过的地接 | 我们装成杂志，不像决策工具 |
| 针对「我这次」的答案 | 日期、人数、落地时刻 | 三日 Markdown 对所有人相同 |
| 减少决策疲劳 | 场景名单（Infatuation「加班后」） | 指南太完整，付费层还是完整 |

Vogue 2025：在 AI 和大众内容之后，**被信任的人替你决定**才是奢侈品。不是又一篇「十件必做」。

## 3. 我们现有付费物为什么不像能买的

过境卡、PDF、淡季桌、街区预览——全是**静态文件**。用户路径是：注册 → 打开储物柜 → 下载 → 不知道和自己的周四有什么关系。

没有一个步骤回答：「我 10 月 14 日到东京住四晚，今晚该干什么。」

没有一个步骤让人感到**不买会亏**：通票买错、吉卜力没抽、星期二撞上闭馆。

## 4. 付费点应该长什么样

**产品：按你的日期生成的 72 小时出行简报（Trip Brief）。**

输入：城、到达日、晚数、同行（独行 / 两人 / 带小孩）。

输出，全部针对这几天：

1. **现在订还是已经晚了** — 提前期 vs 距今天数。晚了就给替代，不要假装还能挤进去。
2. **你在的那几天谁关门** — 巴黎星期二卢浮宫，罗马许多博物馆周一。
3. **住这两个街区，不要住那个** — 按行程形状，不是永恒推荐。
4. **不要把钱交给这些东西** — 通票、机场黄牛、该用交通卡的出租车。一单 > 年费。
5. **落地四小时** — 嵌进这次航班窗口，不是单独一篇。
6. **地理上说得通的日子** — 禁止南北横穿。

免费只露一条闭馆 + 一条「该订了」的标题。完整简报是 Pro。Max 仍是发稿前街区。

购买句不是「解锁储物柜」，是：**「一次机场出租车，就够一年。」**
